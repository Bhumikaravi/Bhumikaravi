### 🌟 Featured Projects

#### 🤖 [Smart Inventory Planning Assistant](https://github.com/Bhumikaravi/Agentic_AI_Project) (Agentic AI)
- **Problem:** Small shops suffer severe financial loss due to manual stock estimation, stockouts, and over-stocking.
- **Solution:** Autonomous multi-agent coordination system utilizing a **Planner Pattern** with specialized agents: Planner Agent, Executor Agent, Feedback Agent, Replanner Agent, and Local LLM Agent.
- **Tech Stack:** Python, Flask, SQLite, Rule-Based Optimization, Local LLM Integration.
- **Evidence:** Repository contains full working codebase, SQLite database, academic project report, and demo video (`DEMO VIDEO.mp4`).

#### 🎨 [DCGAN Fashion Studio](https://github.com/Bhumikaravi/DCGAN-Fashion-Website) (Generative Deep Learning)
- **Problem:** Generating novel, realistic fashion apparel imagery from latent representations.
- **Solution:** PyTorch Deep Convolutional GAN trained on Fashion-MNIST with an interactive Streamlit studio, live loss tracking, synthetic image generation mode, checkpoint persistence, and Pytest test suite.
- **Tech Stack:** PyTorch, Streamlit, Fashion-MNIST, Pytest, Torchvision.
- **Evidence:** Working interactive studio, serialized model checkpoints, and automated tensor tests.

#### 📊 [Online Retail Data Warehouse & Power BI Analytics](https://github.com/Bhumikaravi/Online-Retail-Data-Analysis-) (Business Intelligence)
- **Problem:** Uncovering customer retention, regional revenue distributions, and sales trends across high-volume transaction data.
- **Solution:** Comprehensive data warehouse analyzing **392,692 cleaned UK retail transactions** across 5 interactive dashboards utilizing 10 advanced DAX measures (`CALCULATE`, `ALL`, `DISTINCTCOUNT`, `FILTER`).
- **Tech Stack:** Microsoft Power BI (`.pbix`), DAX, Star Schema Data Modeling, Excel.
- **Evidence:** Includes complete interactive `.pbix` workbook, cleaned dataset, and 8-page academic DWM report.

#### 💬 [Social Media Emotion Detection](https://github.com/Bhumikaravi/Social-Media-Emotion-Detection-) (NLP & Machine Learning)
- **Problem:** Automating sentiment and emotion detection from unstructured, high-noise social media posts.
- **Solution:** End-to-end NLP classification pipeline featuring regex text normalization, tokenization, stopword filtering, TF-IDF feature extraction (5,000 features), and Logistic Regression.
- **Tech Stack:** Python, Scikit-learn, NLTK, Pandas, Matplotlib, SocialBuzz Dataset.
- **Evidence:** Full Jupyter notebook, distribution visual plots, and Alliance University project report.

#### 🔍 [GitHub Codebase Explainer](https://github.com/Bhumikaravi/github-code-explainers) (Full-Stack GenAI)
- **Problem:** Onboarding onto complex open-source code repositories is time-consuming for beginners.
- **Solution:** Full-stack Streamlit app that ingests public GitHub repositories, parses file trees and abstract syntax trees (AST), and generates structured, beginner-friendly explanations via LLM APIs.
- **Tech Stack:** Python, Streamlit, Google Gemini API, Ollama, AST Analysis.

#### ☕ [Guitar Inventory Management System](https://github.com/Bhumikaravi/gis_java) (OOP Java)
- **Problem:** Designing maintainable, extensible inventory search systems using clean OOP architecture.
- **Solution:** Java application implementing encapsulation, modular search queries, and UML object modeling.
- **Tech Stack:** Java, Object-Oriented Design, UML Architecture.
